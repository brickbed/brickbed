# HTTP API

Brickbed exposes a JSON-over-HTTP API. Requests under `/v1` require `Authorization: Bearer <api-key-or-jwt>` unless a schema rule explicitly permits anonymous end-user access. `GET /health` and `GET /ready` require no credential.

## Endpoint summary

```text
GET    /health
GET    /ready
PUT    /v1/{project}/_schema
GET    /v1/{project}/_schema
POST   /v1/{project}/{collection}
GET    /v1/{project}/{collection}/{id}
PUT    /v1/{project}/{collection}/{id}
PATCH  /v1/{project}/{collection}/{id}
DELETE /v1/{project}/{collection}/{id}
GET    /v1/{project}/{collection}?limit=N&cursor=X
POST   /v1/{project}/{collection}/_query
POST   /v1/{project}/{collection}/_search
```

Projects and collections use lowercase letters, numbers, `_`, and `-`. Names beginning with `_` are reserved. Document identifiers are generated by the server on `POST`; do not include `_id`, `_createdAt`, `_updatedAt`, or `_score` in application documents.

## Create and read a document

```bash
AUTH='Authorization: Bearer dev-key'

curl -X POST http://localhost:3001/v1/demo/posts \
  -H "$AUTH" \
  -H 'Content-Type: application/json' \
  -d '{"title":"Hello Brickbed","status":"draft","tags":[]}'
```

The server responds with `201` and the document including its generated metadata:

```json
{
  "_id": "01KZBKRD04H4K1AGAJX94322BY",
  "_createdAt": 1786022474756,
  "_updatedAt": 1786022474756,
  "title": "Hello Brickbed",
  "status": "draft",
  "tags": []
}
```

```bash
curl http://localhost:3001/v1/demo/posts/01KZBKRD04H4K1AGAJX94322BY -H "$AUTH"
```

`PUT` replaces a document. `PATCH` shallow-merges top-level keys and validates the resulting document. `DELETE` returns `204` on success.

## List and query

```bash
curl 'http://localhost:3001/v1/demo/posts?limit=20' -H "$AUTH"

curl -X POST http://localhost:3001/v1/demo/posts/_query \
  -H "$AUTH" \
  -H 'Content-Type: application/json' \
  -d '{"index":"by_status","params":{"status":"published"},"limit":20}'
```

`list` and `_query` return `{ "data": [...], "cursor": "..." }`. The cursor is omitted when no more results remain. Query parameters must bind a prefix of a declared equality index.

## Search

```bash
curl -X POST http://localhost:3001/v1/demo/posts/_search \
  -H "$AUTH" \
  -H 'Content-Type: application/json' \
  -d '{"query":"object storage","mode":"text","limit":10}'
```

Search responses contain documents with a `_score`. Scores are comparable only inside a single response. See [schema and search](schema-and-search.md) for text, vector, and hybrid behavior.

## Errors

Errors are JSON objects with an `error` field. Common status codes are `400` for invalid requests, `401` for missing or invalid credentials, `403` for denied access, `404` for missing resources, `422` for a request body of the wrong JSON shape, and `502` for an embedding-provider failure.

This document is the current alpha reference, not a long-term API stability guarantee. Breaking changes will be recorded in the [changelog](../CHANGELOG.md).
